# MovieDBDisplay

A Blazor Web App that displays movies from MovieDB.



1\. Sign up at https://www.themoviedb.org/signup 

2\. Download MovieDBDisplay-win-x64.zip from latest release and extract.

3\. Open appsettings.json in Notepad.

4\. Replace PASTE\_YOUR\_TMDB\_API\_READ\_ACCESS\_TOKEN\_HERE with your TMDB

&#x20;  API Read Access Token (https://www.themoviedb.org/settings/api).

5\. Double-click MovieDBDisplay.exe.
